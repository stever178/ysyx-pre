- 以16进制查看ELF文件的内容

## 1. `readelf -x .text ex18`

## 2. `hexdump ex18`, `od -t x1 ex18`

## 3. `xxd ex18`

## 4. `objdump -s ex18`
```sh
# 查看节的16进制内容
objdump -s your_file.elf                # 显示所有节的内容

# 查看特定节的内容
objdump -s -j .text your_file.elf       # 查看.text节

# 同时显示反汇编和16进制
objdump -D your_file.elf                # 反汇编所有可执行代码
objdump -d your_file.elf                # 只反汇编.text节

# 以Intel格式显示
objdump -M intel -d your_file.elf
```

## 5. 使用 Vim 查看
```sh
# 打开文件
vim your_file.elf

# 在vim中转换为16进制模式
:%!xxd
# 或直接使用
vim -b your_file.elf  # 二进制模式打开
:%!xxd                # 转换为16进制显示

# 从16进制模式返回普通模式
:%!xxd -r
```
